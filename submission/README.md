# Submission artefacts

Built from the repository, not written separately, so they cannot drift from what
the code actually does.

| File | Source | Upload field |
|---|---|---|
| `DoubleTake-README.pdf` | `/README.md` | README document |
| `DoubleTake-business-proposal.pdf` | `/docs/business-proposal.md` | Business proposal, PDF |
| `DoubleTake-business-proposal.pptx` | generated deck, 8 slides | Business proposal, PPT |

To rebuild after editing the markdown, regenerate the PDFs with the converter in
the scratch directory, or open the markdown in any tool that prints to PDF. The
deck is generated by a script rather than hand-edited, so a change to the numbers
means editing the script and re-running it.

The PDFs and the deck are gitignored: they are build output, and the markdown is
the source of truth.
